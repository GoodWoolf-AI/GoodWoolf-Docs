# Publish a Model Update

Publishing a model update is similar to publishing a new model. The difference is that the weights are the result of NTP, SFT, RL, or aggregation of model deltas, rather than the creation of randomized weights (`RND`).

To publish a model update:

1. Create Safetensors weights from your trained model checkpoint:

```bash
gw save <vendor>/<model> --load-path $GOODWOOLF_MODELS/<vendor>/<model>/chpt.pt
```

2. Upload the updated weights to a public URL (e.g., a Hugging Face model):
- `$GOODWOOLF_MODELS/<vendor>/<model>`

3. Create a PR for the [Training Ledger](/features/training-ledger) repo with the ledger file:
- `<gw_ledger_repo>/<vendor>/<model>/training.ledger.json`

Add a new entry to the model ledger using the stage code that produced the weights:
```bash
gw ledger <vendor>/<model> --create NTP
```

Use `NTP`, `SFT`, `RL`, or `AGG` for base pretraining, fine-tuning, reinforcement learning, or aggregated updates. `RND` is reserved for publishing new randomized models.

Update the `training.ledger.json` in (3) and set the new entry's `url` to the URL in (2) where the updated weights are uploaded. Set the `operator` to the matching stage code. Set the `inputs` to the base training model or a list of aggregated models, each referenced by its `<MODEL_ID>`. Check the entry:
```bash
gw ledger <vendor>/<model> --check
```

Use `--model-id` when working with a specific ledger entry:
```bash
gw pull <vendor>/<model> --model-id <MODEL_ID>
gw checkout <vendor>/<model> --model-id <MODEL_ID>
gw merge <vendor>/<model> --data-name <DATASET> --model-id <MODEL_ID>
```

`gw merge` validates the new checkpoint on the requested dataset before merging it into the active model. The remaining steps to publish the model update PR are the same as for a new model.
