# Naming Conventions

The usage examples use the following template variables:
- `<dataset>` - Bundled dataset name.
- `<vendor>/<model>` - Model namespace containing the vendor (owner) name and model ID.
- `<gw_repo>` - Path to the repo's root directory (cloned via Git).
- `<gw_ledger_repo>` - Path to the [Training Ledger](https://huggingface.co/goodwoolf/goodwoolf-ledger) repo's root directory (cloned via Git). The project reads this path from the environment variable `GOODWOOLF_LEDGER`.
