# Download Model Weights

Models are trained starting from base weights. Gradients from the updated models are then aggregated to update the base weights. To create and publish base weights follow [Create a new model](create-model) and [Publish a new model](publish-model).

To download the current base weights for a given model:

```bash
goodwoolf pull <vendor>/<model>
```
